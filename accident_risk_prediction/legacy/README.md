# Legacy code (reference only)

The per-sequence pipeline used before the collision-time upgrade. These files
are not maintained and several no longer run from here, because the modules
they import were replaced.

To run the old pipeline exactly as it was (for example on the hand-labelled
sequences in `data/sequences/` with the old checkpoints), extract
`pre_upgrade_snapshot.zip` into an empty folder and run it from there.
